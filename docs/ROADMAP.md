# 路线图

路线图记录项目能力成熟度，不等同于承诺发布日期。当前优先级是把“本地可用、文档清楚、VSIX 可安装、核心调度可靠”打磨稳定。

## 已完成

### 基础框架与界面

- [x] VS Code 扩展骨架
- [x] 主面板与侧边栏入口
- [x] 会话与任务管理
- [x] 中文界面文案
- [x] 关键按钮与面板状态提示

### 调度能力

- [x] 单任务派发
- [x] 每执行器独立队列
- [x] 自动派发
- [x] 自动接续
- [x] 自动重连与健康探测
- [x] 任务取消、重试、复制、删除
- [x] 中断识别、中文恢复建议和临时错误自动重试

### 执行器

- [x] 固定 OpenAI 兼容 API 执行器
- [x] Responses API 与 Chat Completions 请求协议
- [x] 固定 API 工具调用与工作区读写
- [x] Codex、OpenCode、Claude Code、Gemini、Aider 命令行执行器
- [x] MCP 客户端执行器
- [x] 内置 HTTP 中继服务执行器
- [x] 默认关闭不可真实开发的占位执行器

### 开源发布

- [x] 中文 README
- [x] 英文 README
- [x] 文档索引
- [x] 发布说明与发布检查清单
- [x] 安全策略、贡献指南、更新日志
- [x] VSIX 打包忽略规则

- [ ] 增加更细粒度的工作区工具权限配置。
